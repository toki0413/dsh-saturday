# NEB 带优化器试验记录（B2 未解，附实测数字）

日期：2026-09-21 · 相关提交：`99872de`（#128 climbing-image + 收敛报告加固 + `initialBand`）
性质：试验记录，不是已交付能力。**四个候选优化器都试过并全部回退**，`plugins/neb/src/neb.mjs`
现仍只有既有的显式 Euler 路径。不把没验证过收敛性的优化器放进发布面。

## 为什么要动优化器

#128 加的收敛报告第一次让这件事可测量。此前 `analysis.neb` 只回一个 `converged` 布尔，
且内置玩具体系（lj-double-well）的直线等距带恰好是 nudged 力的驻定解（`maxF=0`、`nSteps=0`
却报收敛），所以"优化器好不好"在这个仓里从没被真正观测过。有了 `initialBand` 之后，
给一条弯曲初始带就能量出优化器的实际表现——结论是它不行。

## 测量条件

体系 `ljDoubleWell()` 默认参数（ε=1、σ=1、separation=4、confinementK=0.5、cutoff=6），
N=7 像元，两端点先 `quench` 到阱底，中间像元按 `y = k·sin(πt)` 加弯。
`ftol=1e-6`、`maxSteps=3000`、`dt0=0.05`、`dtMax=0.2`、`springK=1`。
oracle 势垒 = `E(0,0,0) − E(端点)` = **0.88398845**（鞍点位置由镜像对称性精确给定在原点，
与 NEB 无关，可独立逐点求值）。

## 四种做法与读数

| 优化器 | 结果 | 关键读数 |
|---|---|---|
| 既有 Euler（升则折半、降则 1.02×、下限 1e-5） | 3000 步不收敛 | maxF 2.40e-1 → 7.35e-2；kink=0.4 的中心像元 y 仅从 0.400 变到 0.401；势垒 0.937545（偏高 5.36e-2）；dt 长期贴 1e-5 下限 |
| FIRE I（标准顺序：先 kick+drift，再算 P=ΣF·v） | **发散** | kink=0.4 → maxF 1.91e+30、势垒 5.43e+58；kink=1.2 → 2.59e+20；kink=0.05 → 8.29e+50；dt 塌到 1e-8 仍发散 |
| 过阻尼下降 + 回溯，单调量 Σ‖F_i‖² | 停滞 | 13 步 stagnated，maxF 卡在 5.50e-2，势垒 0.93811（偏高 5.41e-2） |
| 过阻尼下降 + 回溯，单调量 max‖F_i‖ | 停滞（弱信号） | 9 步 stagnated，maxF 5.44e-2；但 kink=0.05 时降到 3.23e-3（势垒误差 7.9e-4） |
| 逐像元独立步长（delta-goldingberg 风：自己的力变小则 ×1.15，否则 ×0.5） | 停滞，**且推翻上面的诊断** | kink=0.4：1014 步 stagnated，maxF 1.28e-1，中心像元 y 仅从 0.400 到 0.4005；kink=1.2：3000 步未收敛，maxF 3.06e-1；kink=2.5：199 步 stagnated；kink=0.05：降到 4.12e-3（势垒误差 7.95e-4）；climb+逐像元：3000 步 maxF 2.87e-1 |

顺带记一个自己踩的实现坑：FIRE 的功率判据若放在 kick 之前，`v` 恒为零 → `P≡0` → 每步都走
"清速度 + 缩步长"分支，带一动不动（`maxF` 全程等于初值）。顺序修正后才暴露它真的会发散。

## 诊断（为什么停滞，不是符号写错）

1. nudged 力把真实梯度的**切向分量投影掉**（`F = kΔd·τ̂ − ∇E + (∇E·τ̂)τ̂`），切向只剩弹力差。
   等距时弹力差为零——这正是直线等距带驻定的原因，也意味着**像元无法沿路径滑动来重排间距**。
2. 弯曲带的不等距让某些像元的弹簧力成为 maxF 的主导项（初值 0.24 > 中心像元的束缚力 0.20）。
   降中心 y 与均衡相邻间距这两个目标在**单一全局步长**下互相冲突：任何使前者改善的步都会使后者的
   某个像元力变大，于是单调判据（无论 Σ‖F‖² 还是 max‖F‖）在 5.4e-2 处无路可走。
3. 小 kink（0.05）能降到 3.2e-3、大 kink 卡在 5.4e-2，符合"冲突强度随初始畸变增大"的读法，
   不是实现反号。
4. FIRE 的发散是同一堵墙的另一个表现：LJ 排斥壁曲率极大，显式速度格式一旦越过驻定点就被放大，
   清速度的时机总在越界之后。

## 改判（逐像元实验带来的新结论）

逐像元步长本来是为了拆开"降中心 y"与"均衡相邻间距"的冲突，实测它也在同一处停下，而且停的方式把
上一节的归因推翻了一半：中心像元 y 从 0.400 只走到 0.4005——不是步长被压制，而是**这个方向对它自己
的力模长就不是下降方向**。具体机制：像元沿垂直方向下移会减小束缚力（k·y），但同时增大它自己的弹力项
（邻元仍在 y≈0，切向随之倾斜、间距改变）。于是 grow 与 shrink 两条路都被否，它的 dt 同样贴地。

推论：**症结不在步长控制，而在"带参数化 + 坐标式下降"这个求法本身病态**（四个步长类方案在同一位置
停住）。另两个看似更简单的改法也已排除：

- 去掉弹力、直接对带能量作共轭梯度/拟 Newton：会把全部像元吸进最近的阱里（弹簧的存在正是为了防坍缩）；
- 先能量下降、再按弧长重参数化：同样拦不住向阱内坍缩。

## 下一片（B2'）的候选，按代价排序

1. **逐像元步长**（每像元独立 dt，单调判据按像元施加）：最小改动，直接解开第 2 点的冲突。
2. **重参数化切向步**：在 nudged 收敛之外，单独按弧长把像元沿带重新分布（经典做法，代价中等）。
3. **换求解对象**：不靠带参数化，改 dimer 法或改进的 tangent + 拟 Newton（L-BFGS 自实现约 200 行，
   零依赖可行），鞍点判据变成"一个梯度的最小奇异值 ≥ 0"。
4. 保留 climbing image（已交付）与收敛报告（已交付），无论上面选哪条，`stagnated / stepLimitReached /
   trivialStationary` 这三态都别合并成一个布尔。

## 下一片实际推荐：dimer 法

四个步长类方案均否后，B2' 只剩一个真正可能工钱的选项：**不靠带参数化的鞍点搜索（dimer 或 improved
tangent 类）**。它在本题里条件好：可动粒子只有一个（3 自由度），鞍点判据是"梯度小 且 Hessian 恰有一个负
特征值"，而后者可直接复用已有的 `@toki0413/core/eig` 的 `symmetricEigenvalues`（零依赖、闭式可验），
方向旋转与二阶导数用中心差分即可。估计 120 行量级，带一个完整新概念（一个插件里新增 "saddle search"
输出），应作为独立一片做，不挤进本文件里的步长专题。
